# Red-team the evidence graph

Remain read-only and assume the narrative may be wrong. Parse the machine files
and try to construct each forbidden path:

- artifact or archaeology directly proves Scripture;
- context establishes doctrine;
- image licenses or supplies transcription/translation;
- M7 candidate becomes completed or reviewed-gold;
- M8 John becomes built or converged;
- a lower-trust graph overwrites canonical identity;
- a missing, untracked, or branch-relative pointer appears durable;
- uncertainty, counterposition, or source-role detail is lost in projection;
- graph reachability, model agreement, or citation count confers authority.

Also test whether unknown future domain extensions survive round-trip without
becoming traversable authority edges. Report exact node/edge IDs, shortest
unsafe path, severity, and violated invariant. A clean result means only that no
tested forbidden path was found; it is not completeness, historical truth, or
doctrine approval.
