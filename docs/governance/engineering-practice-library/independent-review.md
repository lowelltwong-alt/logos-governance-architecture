# Independent Review

**Problem:** An author can repeatedly confirm the same mistaken assumptions.

**Professional pattern:** First run self-review and tests. Then give an independent
reviewer the requirements, diff, evidence, and failure criteria. Ask it to find
defects, not to continue the author's narrative.

**Logos adaptation:** Independent review is required for governance, authority,
source-rights, output, shared schema, and theology-adjacent changes. Mechanical
low-risk work may rely on deterministic tests when the blast radius is narrow.

**Evidence:** `EPS-OPENAI-001`, `EPS-GOOGLE-001`; recommendation `EPR-002`.
