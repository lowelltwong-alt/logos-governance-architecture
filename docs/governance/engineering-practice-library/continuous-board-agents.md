# Continuous Board-Driven Agents

Practice ID: `EPR-004`

An automated board can reduce forgotten work, but always-on execution can also
multiply cost, conflicts, and review burden. Logos should use it only as a
bounded pilot with explicit claims, budgets, tests, stop rules, and owner gates.

The pattern is not authorized as the default execution model.
