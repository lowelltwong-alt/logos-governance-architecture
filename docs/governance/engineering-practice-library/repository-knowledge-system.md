# Repository Knowledge System

**Problem:** Chat memories disappear, while one giant instruction file becomes
stale and too large to use.

**Professional pattern:** Keep decisions, plans, handoffs, and architecture near
the code. Give agents a short front door and tagged indexes that progressively
route them to relevant detail. Validate links, ownership, and freshness.

**Logos adaptation:** AI front doors, tables of contents, decision registers,
dependency maps, work claims, handoffs, and lesson graphs form the durable system.
New surfaces require tags and "read when" guidance.

**Evidence:** `EPS-OPENAI-001`, `EPS-ANTHROPIC-003`; recommendation `EPR-003`.
