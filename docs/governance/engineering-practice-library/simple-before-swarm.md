# Simple Before Swarm

**Problem:** More agents can look like more progress even when they duplicate work,
consume tokens, and disagree without independent expertise.

**Professional pattern:** Begin with a deterministic workflow or one qualified
agent. Add parallel research agents for separable searches, specialists for distinct
disciplines, and independent reviewers for consequential changes.

**Logos adaptation:** Low-cost workers handle validation and bounded data work.
Greek, Hebrew, textual criticism, theology, ontology, and high-leverage architecture
route to qualified specialists. Swarms require explicit decomposition, budgets,
claims, synthesis, and stop rules.

**Evidence:** `EPS-ANTHROPIC-001`, `EPS-ANTHROPIC-002`; recommendation `EPR-001`.
