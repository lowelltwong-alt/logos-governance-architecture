# Doctrine Layer

This folder is the entry point for stable doctrine-level objects in the Logos repository.

## Why this layer exists

Doctrine nodes preserve major theological objects as governed, reusable structures rather than leaving them scattered across thinker summaries, scripture notes, or applications.

Doctrine nodes are the reusable theological objects that sit between source canon and downstream ordering, weighting, governance, and application. The goal is not merely to store beliefs, but to preserve a structured theological layer that can support derivation into ethics, institutional governance, and LAIRCA-style decision systems.

## Design rules

1. Keep doctrine categories stable even when interpretations differ.
2. Separate doctrine objects from ordering profiles.
3. Separate doctrine objects from weighting profiles.
4. Preserve tensions and disagreements rather than flattening them.
5. Link every major doctrine to source canon, downstream implications, and open questions.

## Standard doctrine node contents

Each doctrine node should eventually include:
- summary
- theological importance
- major source influences
- internal tensions
- governance implications
- AI and decision-system implications
- downstream derivations
- lineage metadata
